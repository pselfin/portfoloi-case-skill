# Скриншоты для кейса

Кадр секции берётся не по границам элемента, а с запасом 30 px сверху и снизу. Без запаса блок выглядит оторванным от страницы. Запас при этом не заходит в содержимое соседнего блока — он подрезается сам.

Съёмка идёт скриптом [shoot.js](shoot.js): он открывает страницу в системном Chrome через puppeteer, гасит анимации, прячет липкое, прокручивает страницу, замеряет блоки и сохраняет кадры прямо в папку кейса. Скрипт не знает ни про CMS, ни про вёрстку конкретного сайта — он работает по геометрии блоков, поэтому годится и для Drupal, и для Битрикса, и для Tilda, и для Next.js.

```
node .cursor/skills/portfolio-case/shoot.js --url <URL> --measure
node .cursor/skills/portfolio-case/shoot.js --url <URL> --out cases/<domain>/screenshots \
  --full pages/01-home.png --shots "#1,01-hero;#2,02-company"
```

Запускать из корня воркспейса. Нужны `puppeteer-core` и Chrome. Puppeteer ищется в `node_modules` воркспейса и вложенных проектов; если его нет, скрипт сам напишет команду установки:

```
npm install --prefix .cursor/skills/portfolio-case puppeteer-core
```

Chrome скрипт находит сам в стандартных местах Windows, macOS и Linux. Нестандартная установка — задать путь через переменную `CHROME_PATH`.

Почему не MCP-браузеры: `user-chrome-devtools` снимает правильно, но не может записать файл в проект — его `filePath` ограничен своими workspace roots. `cursor-ide-browser` пишет файлы, но кадр шире окна собирается мозаикой из повторов страницы. Браузерные инструменты годятся, чтобы найти ссылки, селекторы фильтров и позиции элементов, а снимать нужно скриптом.

## 1. Техника и факты

```
node .cursor/skills/portfolio-case/shoot.js --url https://example.ru/ --tech
```

Отдаёт JSON: заголовки сервера, платформу (Drupal, WordPress, Битрикс, Tilda, Next.js, Nuxt, Shopify, Webflow, Joomla, MODX, OpenCart, InSales, Wix), аналитику, карты, слайдеры, формы с числом полей, защиту форм и счётные факты — сколько страниц в каждом разделе по ссылкам. Пустой массив значит «не нашлось»: это не повод писать «нет», это повод не писать ничего.

## 2. Замер

```
node .cursor/skills/portfolio-case/shoot.js --url https://example.ru/ --measure
```

Вернёт высоту документа, контейнер блоков и список блоков: `top`, `height`, заголовок. Заголовок сразу даёт имя файла.

`rawHeight` в ответе значит, что блоки накладываются отрицательными отступами и высота обрезана по началу следующего блока — так и надо снимать.

Блок выше двух экранов скрипт сам разбирает на части и показывает их как `3.1`, `3.2`. Это спасает сайты, где вся страница лежит в одной обёртке: WooCommerce-магазин из одного блока на 6700 px превращается в дюжину снимаемых секций.

Если вместо блоков вернулась карусель (несколько блоков с одним `top`) или разбиение оказалось слишком дробным, смотреть глубже: `--inspect 3` покажет куски третьего блока, `--inspect 3.2` — куски второго куска.

## 3. Съёмка

```
node .cursor/skills/portfolio-case/shoot.js --url https://example.ru/ \
  --out cases/example.ru/screenshots \
  --full pages/01-home.png \
  --shots "#1,01-hero;#2,02-company;#3,03-services"
```

- `--shots` — список через точку с запятой. `#2,02-company` — второй блок свежего замера, `#3.2,04-works` — второй кусок третьего блока. Координаты берутся из страницы в этом же запуске, поэтому они не устаревают.
- `top,height,имя` тоже работает, но ленивые карты и слайдеры сдвигают вёрстку между запусками. Числа руками — только когда нужен кусок, которого нет в замере, и сразу в том же запуске, что и замер.
- `--full pages/01-home.png` — полный кадр страницы, вместе с тем, что ниже экрана. Работает и на очень длинных страницах: лендинг на 23 000 px снимается целиком.
- `--pad N` — запас, по умолчанию 30. Уменьшать, если в запас всё равно затягивает заголовок соседа.
- `--click "sel1;sel2"` и `--wait 1500` — клики до съёмки: применить фильтр в разделе, раскрыть мобильное меню, открыть вкладку, принять баннер про cookie. Клики идут до скрытия оверлеев, поэтому кнопка согласия ещё на месте. Скрипт пишет по каждому селектору «клик» или «не найден селектор» — проверять эту строку, а не только кадр. Селекторы удобно находить браузерным инструментом.
- `--width 767` — мобильная ширина с мобильным User-Agent и тач-событиями. 767 px — обычный брейкпоинт мобильной вёрстки. Высота экрана считается сама в пропорции телефона: 767×1660.
- `--screen hero-mobile` — кадр ровно в размер экрана, без запаса. Так снимается первый экран: пропорции как у телефона, а не приплюснутая полоса.
- `--keep-overlays` — не прятать липкое и всплывающее. Нужно, когда кадр и есть всплывающее: раскрытое меню, диалог, корзина.
- `--headful` — видимый Chrome. Нужен сайтам, которые отдают заглушку headless-браузеру.
- `--ua "<строка>"` — свой User-Agent. По умолчанию скрипт представляется обычным десктопным Chrome, а не headless.

## 4. Посмотреть на каждый кадр

Открыть сохранённый файл инструментом Read и посмотреть глазами. Не по памяти и не по размеру файла.

Скрипт сам предупреждает в двух случаях: страница загрузилась почти без текста (защита от ботов, редирект, неверный адрес) и кадр получился почти пустым (мало байт на пиксель). Предупреждение — повод открыть и разобраться, а не переснять наугад.

Кадр годный, если:

- заголовок блока внутри кадра;
- низ блока внутри, содержимое не обрезано по строке текста;
- картинки загружены, блок не полупрозрачный;
- в запасе фон или край соседнего блока, но не его заголовок и не его текст;
- страница не повторяется полосами;
- нет липкой панели, баннера и чата.

## Что делать с типичным браком

- **В запас попал заголовок соседа** — переснять с меньшим `--pad`.
- **В кадр попал чужой блок целиком** — блоки накладываются, брать высоту до начала следующего блока.
- **Кадр не совпадает с замером** — вёрстку сдвинула ленивая карта или слайдер, снимать по `#индексу`, а не по числам.
- **Кадр без заголовка блока** — не оставлять: текстовый фрагмент без заголовка не читается как раздел сайта.
- **Белый или полупрозрачный кадр** — блок появляется по скроллу и анимация не доехала. Скрипт гасит анимации и доводит такие блоки принудительно, но если кадр всё равно пустой, помогает `--wait 2000` или `--headful`.
- **Пустая страница, пустой заголовок, язык не тот** — сайт отдал заглушку автоматике. По очереди: `--headful`, свой `--ua`, адрес без `www`, адрес внутренней страницы. Не помогло — сказать пользователю, что сайт закрыт для съёмки.
- **Один блок на всю страницу** — авторазбиение не нашло швов. Смотреть `--inspect 1` и снимать куски, либо резать по числам в том же запуске.
- **Пропал нужный элемент** — скрипт прячет липкое и баннеры по ключевым словам в классах. Если под правило попал нужный блок, снять его отдельным запуском по числовым координатам.

Длинный список — исключение: кадр раздела берётся сверху, до конца второго ряда карточек. Обрезанный третий ряд это не брак, если не обрезан текст.

## Состав кадров

Главная: **все** крупные блоки, один файл на блок. Числового лимита нет, отбор «важных» блоков не делать — в портфолио должна лежать вся главная по частям.

Кроме главной обязательны:

- кадр раздела-списка с применённым фильтром или поиском (каталог, объекты, проекты, вакансии);
- кадр типовой страницы (услуга, товар, проект, вакансия);
- кадр сквозного инструмента, если он есть: конфигуратор, калькулятор, карта.

Полные страницы в `screenshots/pages/` — 2–4 наполненные страницы: главная, раздел, типовая страница. Пустые, тонкие и юридические страницы не снимать, блог целиком не обходить.

Мобильные — 2–3 кадра на ширине 767: `hero-mobile.png` и раскрытое меню `menu-mobile.png` либо ключевой блок `<блок>-mobile.png`. Они подтверждают фразу про адаптив в «Как устроено».

Первый экран снимается одной командой, пропорции телефона получаются сами:

```
node .cursor/skills/portfolio-case/shoot.js --url https://example.ru/ --width 767 \
  --out cases/example.ru/screenshots --screen hero-mobile
```

Раскрытое меню — клик по кнопке меню и кадр от нуля по высоте меню. Селектор кнопки искать в разметке: обычно `#toggle-icon`, `.burger`, `.menu-toggle`, `[class*=hamburger]`.

```
node .cursor/skills/portfolio-case/shoot.js --url https://example.ru/ --width 767 \
  --out cases/example.ru/screenshots --click "#toggle-icon" --wait 1000 \
  --pad 0 --shots "0,620,menu-mobile"
```

Высоту меню подобрать по кадру: пустое поле ниже последнего пункта обрезать, весь экран ради пропорции не растягивать.

Сайт из одной длинной страницы (лендинг, Tilda) — это не повод снимать меньше: блоки такой страницы и есть её разделы, снимать все.

## Имена файлов

- Блоки главной: `01-hero.png`, `02-company.png`, дальше по порядку страницы.
- Блоки внутренних страниц продолжают ту же нумерацию.
- Полные страницы: `pages/01-home.png`, `pages/02-services.png`, `pages/03-service.png`.
- Мобильные: `hero-mobile.png`, `menu-mobile.png`.

Пересняли и перенумеровали — удалить файлы со старыми именами, иначе «Экраны» в кейсе не сойдутся с папкой.
