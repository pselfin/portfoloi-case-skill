# portfolio-case

Скилл для Cursor: по ссылке на готовый сайт собирает материалы для портфолио студии — текст кейса от первого лица и набор скриншотов.

Агент проходит главную, разделы-списки, типовые страницы и сквозные инструменты (калькулятор, карта, форма). Результат — папка `cases/<домен>/` с человекочитаемым `case.md` и кадрами, которые можно сразу класть в сетку портфолио.

## Что получается

```
cases/example.ru/
  case.md
  screenshots/
    01-hero.png
    02-services.png
    ...
    hero-mobile.png
    menu-mobile.png
    pages/
      01-home.png
      02-services.png
      03-service.png
```

В тексте: карточка, лид, компания, задача посетителя, «Что сделали» по глубине сайта, подтверждённая техника, список экранов. Без выдуманной конверсии, без аудита клиента и без личных телефонов.

## Окружение

| Что | Зачем |
|---|---|
| [Cursor](https://cursor.com) | Скилл кладётся в `.cursor/skills/portfolio-case/` и вызывается, когда в чате дают URL и просят кейс / скриншоты / текст для портфолио. |
| [Node.js](https://nodejs.org/) 18+ | Запуск `shoot.js`. |
| npm | Установка `puppeteer-core`. |
| Google Chrome | Съёмка страниц. Подойдёт Chromium или Microsoft Edge, если Chrome нет. |
| Сеть до целевого сайта | Скрипт открывает живой URL, не локальный архив. |

ОС: Windows, macOS, Linux. Chrome ищется в стандартных путях. Нестандартная установка:

```
set CHROME_PATH=C:\Path\To\chrome.exe
```

На macOS / Linux — `export CHROME_PATH=...`.

## Установка

Склонировать репозиторий в воркспейс портфолио (или положить папку скилла в `.cursor/skills/portfolio-case/`).

```
git clone git@github.com:pselfin/portfoloi-case-skill.git
```

Поставить зависимость съёмки один раз:

```
npm install --prefix .cursor/skills/portfolio-case puppeteer-core
```

`puppeteer-core` в репозиторий не входит: скрипт ищет его в `node_modules` папки скилла, корня воркспейса и вложенных проектов. Если пакета нет — напишет ту же команду установки.

Полный Chrome через Puppeteer ставить не нужно: используется системный браузер.

## Как вызвать

В чате Cursor дать ссылку и попросить кейс:

```
Собери кейс для портфолио: https://example.ru/
```

Дальше агент сам читает `SKILL.md`, открывает сайт, запускает `shoot.js` и пишет файлы в `cases/`.

Ручной запуск скрипта — из корня воркспейса, не из папки скилла.

## Как это устроено

Две части.

**Агент** читает скилл и ведёт кейс. Смотрит сайт в браузере (ссылки, фильтры, селекторы меню), собирает факты командой `--tech`, пишет каркас `case.md` по `template.md`, снимает кадры, проверяет каждый PNG глазами и сверяет список «Экраны» с диском.

**`shoot.js`** не знает CMS и классы вёрстки. Открывает системный Chrome через Puppeteer, гасит анимации, прячет липкие панели и чаты, прокручивает страницу и режет её по геометрии блоков. Поэтому один и тот же скрипт снимает Drupal, Битрикс, Tilda, WordPress и Next.js.

Почему не встроенный браузер Cursor: MCP-инструменты либо не пишут файл в проект, либо склеивают широкий кадр мозаикой. Ими удобно найти селектор фильтра, снимать нужно скриптом.

### Команды съёмки

Техника и счётные факты (платформа, аналитика, карты, формы, сколько страниц в разделах):

```
node .cursor/skills/portfolio-case/shoot.js --url https://example.ru/ --tech
```

Замер блоков (`top`, `height`, заголовок):

```
node .cursor/skills/portfolio-case/shoot.js --url https://example.ru/ --measure
```

Кадры секций и полная страница:

```
node .cursor/skills/portfolio-case/shoot.js --url https://example.ru/ \
  --out cases/example.ru/screenshots \
  --full pages/01-home.png \
  --shots "#1,01-hero;#2,02-company;#3,03-services"
```

Мобильный первый экран — ширина 767, пропорция как у телефона (767×1660):

```
node .cursor/skills/portfolio-case/shoot.js --url https://example.ru/ --width 767 \
  --out cases/example.ru/screenshots --screen hero-mobile
```

Полезные флаги: `--click` и `--wait` (фильтр, меню, cookie), `--pad` (запас, по умолчанию 30 px), `--headful` и `--ua` (сайт режет headless), `--keep-overlays` (сам кадр — раскрытое меню).

Полный набор флагов и критерии годного кадра — в [screenshots.md](.cursor/skills/portfolio-case/screenshots.md). Правила текста и проверка перед сдачей — в [SKILL.md](.cursor/skills/portfolio-case/SKILL.md).

## Что скилл сознательно не делает

- Не угадывает URL и не пишет кейс по закрытому сайту (капча, пустая страница, вход).
- Не выдумывает эффект «выросла конверсия», если цифр не дал заказчик.
- Не описывает пустые и устаревшие разделы и не тащит личные телефоны в текст.
- Не обходит блог целиком и юридические страницы ради полноты.

Если автоматическая съёмка не проходит даже с `--headful`, агент останавливается и просит доступ или готовые скриншоты.
